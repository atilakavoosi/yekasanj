# یکاسنج (Yekāsanj)

مبدل آنی یکاهای فیزیک — سریع، دقیق و کاملاً فارسی.

**دمو زنده:** [yekasanj.vercel.app](https://yekasanj.vercel.app)

## این پروژه چیست

هر کسی که فیزیک خوانده باشد این لحظه را می‌شناسد: وسط حل یک مسئله، یک عدد با یکای اشتباه ظاهر می‌شود و باید سریع psi را به پاسکال، یا کالری را به ژول تبدیل کند. جستجوی «convert psi to pascal» در گوگل کار می‌کند، اما کند است، پر از تبلیغ است و برای فارسی‌زبان‌ها طراحی نشده.

**یکاسنج** یک مبدل تک‌صفحه‌ای است که این مسئله‌ی کوچک اما تکرارشونده را حل می‌کند: بیش از ۲۰ کمیت فیزیکی و صدها یکا، با تبدیل آنی هنگام تایپ، جستجوی سریع، و رابط کاربری کاملاً فارسی و راست‌به‌چپ.

## چرا ساختمش

در حین حل تمرین‌های فیزیک، نیاز مداوم به تبدیل یکا یکی از کوچک‌ترین اما آزاردهنده‌ترین وقفه‌هاست. هدف این بود که ابزاری بسازم که این وقفه را به کمتر از یک ثانیه برساند — بدون کلیک اضافه، بدون تبلیغ، بدون طراحی به‌هم‌ریخته.

## ویژگی‌ها

- **۲۲ کمیت فیزیکی**: طول، مساحت، حجم، زمان، جرم، سرعت، شتاب، تکانه و ضربه، نیرو، فشار، انرژی و کار، توان، چگالی، دما، بار الکتریکی، جریان، ولتاژ، مقاومت، خازن، فرکانس، طول موج و میدان مغناطیسی.
- **تبدیل آنی** هنگام تایپ، در هر دو جهت (فیلد مبدأ یا مقصد را — هرکدام بخواهید — تایپ کنید).
- **موتور تبدیل صحیح ریاضی**: تبدیل‌های خطی از طریق یکای پایه، و تبدیل‌های آفین (مثل دما) با فرمول اختصاصی — نه ضرب ساده‌ی نادرست.
- **فرمت‌بندی هوشمند اعداد**: جداکننده‌ی هزارگان، نماد علمی برای اعداد خیلی بزرگ/کوچک، و حذف کامل خطاهای اعشاری مثل `0.30000000000000004`.
- **جستجوی سراسری** یکاها با نام فارسی، انگلیسی، نماد یا نام‌های جایگزین.
- **جابه‌جایی یکاها** با یک کلیک، **کپی نتیجه** با تأیید بصری، و **تبدیل‌های اخیر** ذخیره‌شده در مرورگر.
- **کنترل دقت نتیجه** (تعداد ارقام معنادار).
- کاملاً **راست‌به‌چپ و فارسی**، ریسپانسیو در موبایل و دسکتاپ، و مدیریت ورودی نامعتبر بدون کرش.

## استک فنی

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)
- [lucide-react](https://lucide.dev) برای آیکون‌ها
- فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn) برای تایپوگرافی فارسی
- بدون بک‌اند — همه‌چیز کلاینت‌ساید، با `localStorage` برای تاریخچه‌ی تبدیل‌های اخیر

## معماری

```
types/unit.ts             تایپ‌های Category و Unit
data/categories/*.ts      تعریف داده‌ی هر دسته از کمیت‌ها و یکاهایشان
lib/conversion.ts         موتور تبدیل (خطی + آفین)
lib/format.ts             فرمت‌بندی و پارس اعداد
lib/search.ts             جستجوی فازی یکاها و دسته‌ها
lib/recent.ts             تاریخچه‌ی تبدیل‌های اخیر
components/               کامپوننت‌های رابط کاربری
```

منطق تبدیل کاملاً از رابط کاربری جدا است؛ افزودن یک کمیت یا یکای جدید فقط به یک آبجکت داده در `data/categories/` نیاز دارد.

## توسعه‌ی محلی

```bash
npm install
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

برای بیلد نسخه‌ی نهایی:

```bash
npm run build
npm run start
```

## ایده‌های آینده

- افزودن حالت تیره/روشن دستی (در حال حاضر بر اساس تنظیمات سیستم است)
- پشتیبانی از فرمول‌های تبدیل چندمرحله‌ای (مثل واحدهای مرکب سفارشی)
- افزودن دسته‌های بیشتر (مثل نور و اپتیک) در صورت نیاز واقعی کاربران
- حالت آفلاین کامل (PWA)
